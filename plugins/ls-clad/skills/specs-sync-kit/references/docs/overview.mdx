# Overview

> Upstream docs for figures and diagrams: [Overview](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/overview).

### Prerequisites

- Lens Studio v5.25 or later
- Spectacles SnapOS v.5.59 or later

### About Sync Kit

Sync Kit is a Lens Studio package that enables the development of [Connected Lenses for Spectacles](../../../spectacles/about-spectacles-features/connected-lenses/overview). The package includes scripts and components that can be used to sync data among Spectacles users in shared experiences.

To start building Connected Lenses using Sync Kit, follow the instructions below to [start a new project](#starting-a-new-project) or [update an existing project](#updating-an-existing-project) in Lens Studio.

#### Key Features

This list outlined key features to be familiar with when building Connected Lenses with Sync Kit.

1. [**SessionController**](./features/session-controller): Access information about the current session using SessionController APIs.
2. [**SyncEntity**](./features/sync-entity): Turn any script into an entity that can synchronize data using the SyncEntity class.
3. [**Storage Properties**](./features/storage-properties): Add storage properties to SyncEntities to store data and notify the network of state changes.
4. [**Networked Events**](./features/networked-events): Add networked events to SyncEntities to send one-time messages across the network.
5. [**Instantiator**](./features/prefab-instantiation): Instantiate prefabs across the network.
6. [**Lifecycle**](./lifecycle): Understand the setup flow of a Connected Lens session and when features are ready to use.

#### Package Resources

The Sync Kit package includes the following resources when imported into your Asset Browser:

- [**Interaction Kit**](../spectacles-interaction-kit/get-started.mdx): Included in the package, does not need to be installed separately.
- [**UI Kit**](../spectacles-ui-kit/get-started.mdx): Included in the package, does not need to be installed separately.
- **Connected Lens Module**: Required to connect to the Connected Lenses backend.
- **Location Cloud Storage Module**: Required for colocated mapping.
- **Core**: TypeScript files required for Connected Lenses to function.
- **Components**: TypeScript components and helpers to aid Lens development.
- **Examples**: Resources that demonstrate features and components, including TypeScript and JavaScript files.

### Starting a New project

#### Option 1: Starting a New Connected Lenses Project

> See [Option 1: Starting a New Connected Lenses Project](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/overview#option-1-starting-a-new-connected-lenses-project) in the upstream docs for diagrams.

1. In the Lens Studio home under Sample Projects, open the **Sync Kit** project. This project already includes the Sync Kit package and is configured for Spectacles development.

2. Check that you are logged in to Lens Studio. If not, log in.

3. In the Asset Browser, right click on the Sync Kit package and select **Register to Library**. Registering the package to your library ensures that future updates can be detected. If you already have the package registered to your library, this option will not be available.

#### Option 2: Importing Sync Kit into a New Lens Studio Project

> See [Option 2: Importing Sync Kit into a New Lens Studio Project](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/overview#option-2-importing-spectacles-sync-kit-into-a-new-lens-studio-project) in the upstream docs for diagrams.

To start building a Connected Lenses project for Spectacles from scratch, follow these steps:

1. Install the latest Sync Kit version from the Asset Library via Window > Asset Library > Spectacles > Sync Kit.

2. All the associated packages will be installed automatically into Asset > Packages.

3. After the TypeScript Status panel confirms that compilation is complete, click the Refresh button on the Preview panel.

You can also unpack the Sync Kit package by right-clicking and selecting **Unpack**. Unpacking enables direct editing of Sync Kit but may complicate future upgrades to newer versions. Additionally, when unpacked, import components and modules in your TypeScript files using SyncKit rather than SyncKit.lspkg in your import path.

4. From the Asset Browser, first, drag `Packages/InteractionKit.lspkg/Prefabs/InteractionKit.prefab` into the Scene Hierarchy and then drag `Packages/SyncKit.lspkg/SyncKit.prefab` into the Scene Hierarchy.

Instantiating the prefab before TypeScript compilation is complete may result in a corrupt prefab with missing links to TypeScript script components. Ensure that TypeScript compilation is fully complete before adding a prefab instance to the scene hierarchy.

6. If the Examples included in the SyncKit prefab are no longer needed, disable or delete them from the Scene Hierarchy.

7. The import is complete. Save your project!

### Updating an Existing Project

To import Sync Kit into an existing project that already contains Interaction Kit, follow these steps:

#### Importing Sync Kit into an Existing Lens Studio Project that Contains Interaction Kit

> See [Importing Sync Kit into an Existing Lens Studio Project that Contains Interaction Kit](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/overview#importing-spectacles-sync-kit-into-an-existing-lens-studio-project-that-contains-sik) in the upstream docs for diagrams.

To import Sync Kit to an existing project that already contains Interaction Kit, follow these steps:

1. Check if there is any update available for Interaction Kit. If there is, update it first by right click on the package > Pull Update from Library. See [Upgrading Interaction Kit Guide](../spectacles-interaction-kit/get-started#upgrading-spectacles-interaction-kit-within-a-project)
1. Install the latest Sync Kit version from the Asset Library via Window > Asset Library > Spectacles > Sync Kit.
1. All the associated packages will be installed automatically into Asset > Packages.

1. Follow the steps above under [Starting a New Project > Option 2: Importing Sync Kit into a New Lens Studio Project](#option-2-importing-sync-kit-into-a-new-lens-studio-project).
1. The Interaction Kit references in your project (e.g., in the scene hierarchy and prefabs) should automatically relink to the InteractionKit included in the imported SyncKit package.

#### Updating Sync Kit Within a Project

To upgrade Sync Kit in a project that already includes the package, follow these steps:

1. Open your project in Lens Studio.

1. Log in to Lens Studio.

1. In the Asset Browser panel, right click on the `SyncKit` package folder. Select **Pull Update from Library**. If this option is not available in the context menu, check that you are logged in to Lens Studio.

In the Asset Library, the Sync Kit package thumbnail will show if an update is available. The method outlined above is the recommended way to update your package, rather than selecting Update on the Asset Library thumbnail.

#### Upgrading from Sync Framework

Previous versions of Sync Framework for Spectacles and for mobile are incompatible with Sync Kit. To upgrade a project from Sync Framework to Sync Kit, follow these steps:

1. In the Scene Hierarchy, pull out any colocated Lens content that you may have within the Sync Framework hierarchy.

2. Delete the Sync Framework root scene object from the Scene Hierarchy. Note: If you are using Sync Framework for Spectacles, which includes Interaction Kit, this will also delete Interaction Kit from your scene.

3. Delete the Sync Framework package or resources from the Asset Browser. Note: If you are using Sync Framework for Spectacles, which includes Interaction Kit, this will also delete Interaction Kit resources from your Asset Browser.

4. Import Sync Kit into your project from the Asset Library and add the Sync Kit prefab to your scene.

5. Update Interaction Kit and Sync Kit components throughout your project, e.g., components on scene objects, references in your scene, prefabs, etc.

6. Move any colocated Lens content from Step 1 back into the Sync Kit hierarchy.
