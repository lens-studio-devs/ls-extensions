# Start Menu and Player Mode

> Upstream docs for figures and rendered code examples: [Start Menu and Player Mode](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/features/start-menu-and-single-player).

While Connected Lenses are meant to be experienced together, users should also have the option to enjoy the Lens on their own. For that purpose, the Sync Kit package includes a Start Menu, which has Multiplayer and Solo buttons.

The Start Menu is shown to users when they enter a Connected Lens. If a user selects Multiplayer, they enter the co-located joining flow. If they choose Solo, they skip the joining flow and are put directly into the Lens.

### UI Customization

> See [UI Customization](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/features/start-menu-and-single-player#ui-customization) in the upstream docs for diagrams.

You are highly encouraged to customize the Start Menu to match the design of your Lens. To change the Start Menu visuals, edit the `StartMenu/Prefabs/StartModeController.prefab` asset in the Sync Kit package rather than the linked instance in the scene; the **StartMenu** scene object (`SyncKit / HiddenFromSceneView / EnableOnAwake / StartModeController / StartMenu`) is disabled at edit time and shown at launch by `StartModeController`. Button labels and alert text are localization keys in `Localization/Asset/strings.json`, not literal text (see `StartMenu/README.md` in the package).

- **Graphic**: The icon graphic on the top for the Start Menu.
- **Lens Title**: The title for the Lens.
- **Lens Version**: The version number for the Lens.
- **Multiplayer Button**: The button to start a multiplayer session. Update the Multiplayer buttons to suit your design. Currently, the default visuals are using [UI Kit](../../spectacles-ui-kit/get-started.mdx), it allows you to customize the appearance and behavior. You may also want to add a title splashscreen for your Lens. The example buttons include [Interaction Kit](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-interaction-kit/get-started) components to make them pinchable – keep these components or use them as a guide for how to set up your own buttons.
- **Solo Button**: The button to start a singleplayer session.

In the Inspector panel for the StartMenu script, ensure the **Single Player Button** and **Multi Player Button** inputs are populated with the UI Kit button components (`BaseButton`, e.g. a `RectangleButton`/`CapsuleButton`) for each button.

The **Start Menu Distance From User** input sets how far in front of the user in centimeters the Start Menu appears when they join the Lens.

### Single Player Configuration

The Inspector panel for the StartMenu script includes two inputs for configuring single player mode – **Single Player Type** and **Enable On Singleplayer Nodes**.

#### Single Player Type

From the dropdown, choose how single player logic will be handled in your Lens. There are two options:

1. **Mocked Online (Automatic):** When this option is selected, your synchronization logic will automatically work for single player. The Lens will use a mock Connected Lens module to mimic communication with the Connected Lenses server.
1. **Manual:** When this option is selected, you will need to handle your own single player logic.

#### Enable on Singleplayer Nodes

The scene objects added to this list are enabled after a user selects Solo from the Start Menu. By default, this input is populated with the **EnableOnReady** scene object.

### Start Mode Configuration

> See [Start Mode Configuration](https://developers.snap.com/spectacles/spectacles-frameworks/spectacles-sync-kit/features/start-menu-and-single-player#start-mode-configuration) in the upstream docs for diagrams.

In Session Controller Component, there are three options to configure `Start Mode` to set up how the session starts.

- **Start Menu**: (default) Displays the Start Menu, which lets the user choose between Solo and Multiplayer. A failed connection, or pressing Multiplayer with no internet, shows the matching alert on the menu and the user retries with the button.
- **Multiplayer**: Starts a multiplayer session immediately without displaying the Start Menu. When a Same Session ID is set, the Lens will enter the dedicated session and start mapping flow directly without prompting for session selection. If Same Session ID is not configured, this will enter the session selection state. A failed join retries silently once a second, up to five times, then falls back to the Start Menu with the alert. A `StartMultiplayer` launch parameter from System UI (for example, joining from Active Nearby) forces this mode regardless of the setting.
- **Off**: The kit does nothing on launch — no Start Menu and no session. Call `SessionController.getInstance().startWithStartMenu()` or `SessionController.getInstance().startMultiplayer()` from your own code when ready. Nothing retries, and failures reach your `SessionController.onConnectionFailed` handler.

**Important:** When skipping Player Mode Selection with multiple Preview Panels active in Lens Studio, use the "Randomize Session ID" option on the ConnectedLensModule to force a new session. Avoid restarting individual preview windows, as they rejoin immediately while other panels remain connected, preventing the session state from fully resetting.

#### Manual Multiplayer Mode Button

This provides users with the flexibility to join a Multiplayer session at any time during the Lens experience. This is particularly useful in scenarios where the experience starts in Solo Mode or requires a user action before joining a connected session.

1. Set **Start Mode** to **Off** on the Session Controller Component, so the kit shows no menu and starts no session on launch.
2. Add an `EnableMultiplayer` script to a Scene Object and wire your own UI Kit button to it.
3. A `StartMultiplayer` launch parameter (the Lens was opened by joining from `Active Nearby` in Lens Explore) still starts multiplayer automatically, even in Off mode.

```typescript
import {SessionController} from "SyncKit.lspkg/Core/SessionController"
import {BaseButton} from "UIKit.lspkg/Scripts/Components/Button/BaseButton"

@component
export class EnableMultiplayer extends BaseScriptComponent {
  @input
  multiplayerButton: BaseButton

  onAwake() {
    this.createEvent("OnStartEvent").bind(() => this.onStart())
  }

  onStart() {
    // Pinch the button to start a multiplayer session.
    this.multiplayerButton.onTriggerUp.add(() => SessionController.getInstance().startMultiplayer())

    // In Off mode failures are not retried; react to them here.
    SessionController.getInstance().onConnectionFailed.add((code: string, description: string) => {
      // Intentional cancellation and errors use the same callback, so check the code.
      if (code !== "CancelledByUser") {
        print(`Connection failed (${code}): ${description}`)
      }
    })
  }
}
```
