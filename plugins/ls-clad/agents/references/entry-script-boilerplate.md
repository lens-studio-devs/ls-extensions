# Authored-scene entry-script boilerplate (full)

Reference for `specs-experience-builder` Essential Pattern #7. Consulted at Phase 2f write time. The file lives at `Assets/Scripts/<ExperienceName>Main.ts`. The full implementation below includes the `@input`-validation guard (Hard Rule 5), the `setColliderDebugAll` walker (Hard Rule 6.7), and the wrapper-pattern `buildScene()` body (Hard Rule 6.2). All are load-bearing; the always-loaded agent body carries only the class shell + `@input` declarations + `onAwake()` stub.

Note the doctrine: semantic roots (the UI panel, the board's anchor slot) are **authored SceneObjects the bootstrap creates and wires to these `@input`s** — `buildScene()` only instantiates runtime content under an anchor the bootstrap already placed. It does not create the anchor itself.

```typescript
import { ScorePanelUI } from "./<ExperienceName>ScorePanelUI";  // class generated by /specs-build-ui (Phase 2d)
const boardPrefab = requireAsset('../GeneratedMeshes/board.glb') as ObjectPrefab;

@component
export class Main extends BaseScriptComponent {
    // Inspector toggle: flip ON to render every Physics.ColliderComponent /
    // BodyComponent in the scene as a wireframe — for diagnosing hit-zone
    // mismatches against the visual mesh. Takes effect on preview restart.
    @input
    debugColliders: boolean = false;

    // Wired by the bootstrap to the UI panel's ScriptComponent (Hard Rule 3).
    // Typed as the UI class directly — Lens Studio resolves the wired
    // ScriptComponent to the underlying class instance at runtime, so no
    // `.getScript()` and no cast.
    @input
    scorePanel!: ScorePanelUI;

    // Authored anchor SceneObject (unit-scale, placed by the bootstrap). Runtime
    // content is instantiated under it; a human can move/rename it in the Inspector.
    @input
    boardSlot!: SceneObject;

    private score = 0;

    onAwake() {
        // Fail loudly if the bootstrap did not wire a required authored ref.
        if (!this.scorePanel || !this.boardSlot) {
            print("Main: required @input not wired (scorePanel / boardSlot). Check Phase B.");
            return;
        }
        this.buildScene();
        this.scorePanel.onStart.add(() => this.startGame());
        if (this.debugColliders) {
            this.setColliderDebugAll(this.getSceneObject(), true);
        }
    }

    private buildScene(): void {
        // boardSlot is an authored, bootstrap-placed anchor — do NOT createSceneObject
        // it here (Hard Rule 5). Only the prefab instance below is runtime content.
        // Default scale (100) preserves Blender-authored size — see GLB scale rule above
        const board = boardPrefab.instantiate(this.boardSlot);

        // Wrapper pattern (Hard Rule 6): collider + Interactable on the unit-scale slot.
        // size = aabb_cm recorded in Phase 2b (filled in Phase 2g)
        const collider = this.boardSlot.createComponent('Physics.ColliderComponent') as ColliderComponent;
        const box = Shape.createBoxShape();
        box.size = BOARD_AABB;  // TODO: verify with aabb_cm
        collider.shape = box;
        this.boardSlot.createComponent(Interactable.getTypeName());
    }

    private startGame(): void {
        this.score = 0;
        this.scorePanel.setScore(this.score);   // push state into UI — never createComponent('Component.Text')
    }

    // Walks the scene tree from `obj` and toggles debugDrawEnabled on every
    // Physics.ColliderComponent and Physics.BodyComponent. Drives the
    // `debugColliders` @input above. BodyComponent is checked separately
    // because getComponent('Physics.ColliderComponent') does not return
    // BodyComponents even though BodyComponent extends ColliderComponent.
    private setColliderDebugAll(obj: SceneObject, enable: boolean): void {
        const c = obj.getComponent('Physics.ColliderComponent') as ColliderComponent | null;
        if (c) c.debugDrawEnabled = enable;
        const b = obj.getComponent('Physics.BodyComponent') as ColliderComponent | null;
        if (b) b.debugDrawEnabled = enable;
        for (let i = 0; i < obj.getChildrenCount(); i++) {
            this.setColliderDebugAll(obj.getChild(i), enable);
        }
    }
}
```
